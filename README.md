# Bugs/Suggestions
## Common fixes
> [!TIP]
> Please try these before you open an issue.
- **Force-reload** the page so that any new updates take effect (`CMD`+`SHIFT`+`R` on Mac and `CTR`+`SHIFT`+`R` elsewhere).
- Remember that it can take some time (up to a minute) for changes to be published. If you see that the repo is updated and the website isn't, then give it a few seconds.
